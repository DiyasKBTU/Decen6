# Статус проекта

Обновлено: 30 октября 2026. Работа разбита не на «фичи», а на **циклы**: каждый — законченный процесс со входом, выходом и обратной связью. Если цикл готов, его можно показать целиком.

## Цикл 1. Обращение → ответ с опорой на правила

- **Вход:** текст игрока (+ тип, ник, скриншоты, если есть).
- **Выход:** JSON по контракту: язык, категория, срочность, факты, черновик со ссылками, «нужен ли человек», причины.
- **Как замыкается:** каждый черновик проходит проверку — ссылки только на существующие и найденные поиском пункты, без запрещённых обещаний; при проблеме берётся безопасный шаблон.
- **Что внутри:** очистка → язык → факты → категория (правила + модель) → срочность → дубль → поиск по правилам и прошлым ответам → черновик → проверки.
- **Цифры (valid, 1000 обращений):** выдуманных ссылок — 0; пункт админа в первых пяти найденных — 91,7% (было 67%); черновик цитирует тот же пункт, что админ, — 81,6%; ответ — около 40 мс, p95 37 мс; стоимость без языковой модели — $0.

## Цикл 2. Ответ → решение админа → обучение

- **Вход:** обращения в очереди.
- **Выход:** отправленный, исправленный или переданный ответ + запись в журнале.
- **Как замыкается:** журнал правок выгружается (`/api/admin/feedback/export`), и классификатор дообучается на исправленных категориях (`train_classifier.py --feedback`, вес 3). Эти обращения исключаются из проверки, чтобы не завысить оценку.
- **Интерфейс:** очередь по срочности; карточка — обращение, черновик, блок «На чём основан ответ» (найденные пункты, термины, как отвечали на похожее); правка с проверкой ссылок на лету; «Отправить», «Эскалировать»; кнопка «Новое обращение» для проверки любого текста.

## Цикл 3. Поток обращений → порядок

- **Срочность:** взломы, платежи, угрозы — p0; читы, мошенничество, реклама — p1.
- **Дубли:** повтор, пока первое без ответа. На valid найдено 9 из 18 дублей, отмеченных админами; ни одна одобренная жалоба не задета.
- **Автоответы:** оффтоп, «перевернулась машина», телепорт, принятые шаблоны — без админа. Сейчас без проверки уходит 11% всех обращений: половина репортов и почти ни одной жалобы (решение о наказании по условиям кейса подтверждает админ).
- **Прогон истории (67,7 тыс. жалоб):** читы и мошенничество получали бы ответ за ~1 мин вместо 34–90 мин (медиана); 90-й перцентиль всех жалоб — 49–65 мин вместо 4,8 ч. Это оценка при допущении, что каждая жалоба отнимает у админа одинаковое время.

## Цикл 4. История ответов → новые шаблоны → применение

- **Вход:** 118 тыс. обращений с ответами админов.
- **Выход:** 18 предложений вида «на это админы отвечают так, а сервис — общей фразой».
- **Как замыкается:** админ принимает шаблон во вкладке «Шаблоны» (текст проверяется) → сервис сразу использует его для похожих обращений.
- **Побочный результат:** анализ показал, что на DM, читы и мошенничество без видео админы обычно просят видео. Черновик изменён, совпадение решения с админом — 49% → 60%.

## Цикл 6. Живые тексты от языковой модели

Готово: поиск даёт модели найденные пункты и примеры ответов, модель может сослаться только на них (JSON-схема), текст проверяется, при любой проблеме или задержке больше 3,5 с — шаблон. Проверено на фейковой модели (тесты и прогон 1000 обращений). **Не проверено с настоящим ключом:** нужен `ANTHROPIC_API_KEY` в `.env`, затем `make eval`.

## Цикл 7. Казахский и узбекский

Готово: шаблоны на 6 языках в стиле реальных ответов, восстановление казахских букв, определение языка (украинский не путается с казахским), примеры ответов на том же языке. **Не сделано:** вычитка носителем языка (`copilot/templates.py`, ключи `kk` и `uz`).
