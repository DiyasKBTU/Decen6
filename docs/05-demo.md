# Сценарий защиты

Около 6 минут показа + вопросы. Всё показываем вживую в интерфейсе админа.

## Подготовка (за 10 минут до выхода)

```bash
cd support-copilot
make queue      # свежая демо-очередь: 300 обращений valid
make serve      # сервис на http://localhost:8000
```

На Windows без `make`:

```bash
python scripts/load_queue.py --limit 300 --with-reference
python -m uvicorn copilot.api:app --port 8000
```

Открыть `http://localhost:8000/admin`. Если `out/admin.db` уже есть, `make queue` перезапишет обращения, а принятые шаблоны останутся. Чтобы начать с чистого листа, удалите `out/admin.db` перед `make queue`.

Нужен интернет только для шрифта; без него интерфейс работает на системном шрифте.

## Сценарий

### 1. Проблема (30 секунд, без экрана)

«Админы Grand Mobile вручную отвечают на тысячи обращений, ответы однотипные, а срочное тонет в потоке. По данным, сейчас жалоба на мошенничество ждёт ответа дольше всех — медианно полтора часа, а пустые жалобы закрываются быстрее всех».

### 2. Очередь (30 секунд)

Вкладка «Очередь»: обращения уже отсортированы по срочности, у каждого — категория и одна строка текста. Пометка «можно отправить сразу» — то, что сервис закрыл бы сам.

### 3. Живое обращение — главный цикл (2 минуты)

Кнопка **«Новое обращение»** → Жалоба → текст:

> Arman_Petrov убил меня в зз у банка без причины, скрины есть

Скриншотов: 1 → «Разобрать».

Показать:

- категория «Убийство без повода», срочность P2;
- черновик: «по скриншотам нельзя подтвердить, нужна видеозапись (п. 1.2.2 правил подачи жалоб)…» — объяснить: «мы посмотрели 7 тысяч таких жалоб — админы в 60% случаев просят видео и только в 11% наказывают, поэтому черновик просит видео»;
- блок **«На чём основан ответ»**: поиск нашёл GZ 1.1 (зелёная зона) и пункты правил подачи жалоб; ниже — как админы отвечали на похожие жалобы. «Это RAG: сначала поиск по правилам и прошлым ответам, потом ответ. Ссылаться можно только на найденное».

Затем то же обращение, но с видео: «…, фрапс https://youtu.be/x» → черновик уже предлагает наказание по GZ 1.1 (деморган 60 минут + WARN), а решение подтверждает админ.

### 4. Защита от галлюцинаций (40 секунд)

В любом черновике дописать: «Также нарушен п. 9.9 общих правил». Сразу появится предупреждение «ссылка на несуществующий пункт». «На 1000 проверочных обращений у нас ноль выдуманных ссылок — проверка стоит и на тексте модели, и на правке админа».

Нажать «Вернуть черновик» → «Отправить». Сервис переходит к следующему обращению, действие записано в журнал.

### 5. «Всегда человек» (20 секунд)

«Новое обращение» → Репорт → «оплатил донат, не пришло» → P0, «платёж», ответ без обещаний зачисления, решает человек.

### 6. Новые шаблоны — цикл обучения (1 минута)

Вкладка «Шаблоны»: «на "спасибо" сервис отвечал "уточните вопрос", а админы — "приятной игры"; таких обращений 106». Нажать «Использовать».

«Новое обращение» → Репорт → «спасибо большое админы» → сервис сразу отвечает принятым шаблоном, можно отправить без проверки.

### 7. Цифры (40 секунд)

- 0 выдуманных ссылок на 1000 обращений;
- поиск находит пункт админа в первых пяти в 92% случаев;
- решение черновика совпадает с решением админа в 60% (было 49% до анализа данных);
- прогон истории: читы и мошенничество получали бы ответ за ~1 минуту вместо 34–90;
- $0 и ~40 мс без языковой модели; с Claude Haiku — около $0,0003 за обращение (оценка, лимит кейса $0,002).

## Вероятные вопросы

| Вопрос | Ответ |
|---|---|
| Где тут ИИ, если много правил? | Классификатор обучен на 46 тыс. примеров, поиск по базе знаний — это RAG, языковая модель пишет живой текст при наличии ключа. Правила там, где они надёжнее и объяснимее. |
| Откуда разметка, если её не дали? | Из ответов админов: «наказание выдано верно» — апелляция, «мут за 2.1» — оскорбление. 46 тыс. примеров. |
| Почему так много «нужен человек»? | По условиям кейса наказание подтверждает админ. Без админа уходит то, где ошибиться нельзя: оффтоп, эвакуатор, телепорт, принятые шаблоны. |
| Насколько точны категории? | 86% по прокси-меткам из ответов админов. Честная цифра — после ручной разметки, это следующий шаг. |
| Как с казахским и узбекским? | Шаблоны на 6 языках, восстанавливаем казахские буквы из игровой кодировки, не путаем с украинским. Тексты осталось вычитать носителю. |
| Что будет, если модель ошибётся? | Модель может сослаться только на найденные пункты, её текст проверяется, при любой проблеме — безопасный шаблон. |
| Как это внедрить? | Игра шлёт обращение в `POST /triage` или в `/api/admin/tickets` и получает JSON. Отдельный сервис, доступ к коду игры не нужен. |
