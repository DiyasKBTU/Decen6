# Наша идея

## В одном абзаце

Мы сделали помощника, который за доли секунды разбирает обращение игрока и готовит ответ, опираясь на настоящие правила игры и на то, как админы отвечали раньше. Решения (категория, срочность, нужен ли человек) принимает понятный код и обученная модель, а не «ИИ на удачу». Текст ответа всегда проверяется: каждый пункт правил существует, нет обещаний разбана или возврата. Всё сомнительное уходит человеку. Админ видит очередь по срочности, черновик и на чём он основан, а его правки становятся обучающим сигналом.

## Три принципа

1. **Решает код, пишет шаблон или модель.** Категорию, срочность, допустимые пункты правил и «нужен ли человек» определяют правила и обученная модель. Их решения можно проверить и объяснить — у каждого есть причины.
2. **Ничего не выдумываем.** Перед ответом система ищет пункты правил (RAG). Черновик может сослаться только на найденный пункт, а проверка ловит любой несуществующий номер. На 1000 проверочных обращений — ноль выдуманных ссылок.
3. **Сомневаешься — отдай человеку.** Наказания, апелляции, платежи, взломы, угрозы и неуверенность — всегда к админу. Сервис помогает, а не решает за админа.

## Главный цикл (его показываем на защите)

```
Игрок пишет
   │
   ▼
Разбор: язык, факты, категория, срочность, дубль?
   │
   ▼
Поиск (RAG): пункты правил + как админы отвечали на похожее
   │
   ▼
Черновик со ссылками только на найденное → проверка
   │
   ▼
Админ в интерфейсе: видит черновик и основание → отправляет / правит / передаёт
   │
   ▼
Правка сохраняется → на ней дообучается модель, из похожих правок рождаются новые шаблоны
```

## Что нашли в данных и как это использовали

Это то, что отличает решение от «просто прикрутили нейросеть»:

| Находка | Что сделали |
|---|---|
| Разметки категорий нет, но ответ админа её выдаёт: «наказание выдано верно» — апелляция, «мут за 2.1» — оскорбление | Получили 46 тыс. размеченных примеров бесплатно и обучили на них классификатор |
| На DM, читы и мошенничество **только со скриншотами** админы в ~60% случаев просят видео и лишь в ~10% наказывают | Для таких жалоб черновик просит видеозапись, а не предлагает наказание. Совпадение решения черновика с решением админа выросло с 49% до 60% |
| Повтор жалобы админы считают дублем почти только пока первая ещё без ответа | Склеиваем только такие повторы и не трогаем повторную подачу с доказательствами |
| «+» в репорте — это не спам, а просьба о телепорте на мероприятие | Отдельный ответ, решает админ |
| Сейчас мошенничество ждёт ответа дольше всех (медиана 90 мин), а пустые жалобы закрываются быстрее всех | Очередь по срочности: по оценке, читы и мошенничество получали бы ответ за ~1 минуту |
| На «спасибо» сервис отвечал «уточните вопрос», а админы — «приятной игры» | Поиск групп похожих обращений предлагает новые шаблоны, админ принимает их в один клик |

## Как это закрывает критерии

| Критерий | Чем закрываем |
|---|---|
| Классификация (25%) | Правила + классификатор на разметке из ответов админов; где правила надёжнее (читы, DM, мошенничество), модель их не перебивает |
| Черновики (30%) | Шаблоны в стиле реальных админов, решение черновика согласовано с тем, как админы решают такие случаи; при наличии ключа — живой текст от модели в тех же рамках |
| Без галлюцинаций (20%) | RAG + белый список пунктов + проверка каждого номера в тексте; 0 выдуманных ссылок на valid |
| kk / uz (15%) | Шаблоны на 6 языках, восстановление казахских букв, примеры ответов на том же языке; осталось вычитать носителю |
| Цена и скорость (10%) | Без модели — $0 и ~40 мс; с моделью Claude Haiku — ~$0,0003 за обращение (оценка), при задержке больше 3,5 с — шаблон |
| Бонусы | Дубли, интерфейс админа с журналом правок, новые шаблоны из групп похожих обращений, прогон истории |

## Чего мы сознательно не делаем

- Не даём сервису наказывать или снимать наказания — только предлагать.
- Не отвечаем автоматически сырыми прошлыми ответами админов: проверили, они слишком шумные. Готовые ответы — только из шаблонов, которые админ принял.
- Не верим словам игрока как фактам: черновик пишет «по предоставленным материалам».
