# Контекст проекта для ИИ-ассистента и новых участников

Этот файл читается первым при продолжении работы в новом чате. Держите его актуальным: после заметного изменения обновите разделы «Состояние» и «Что дальше».

## О проекте

Decentrathon 6.0, кейс 03 от Grand Mobile (мобильная ролевая игра). Сервис триажа обращений игроков: язык, категория (14 из `taxonomy.json`), приоритет p0–p3, спам и дубли, факты, черновик ответа со ссылками на правила, `needs_human`. Сдаём HTTP `POST /triage` (контракт в [docs/01-task.md](docs/01-task.md)), `make predict IN= OUT=` и отчёт. Оценка: категории и приоритет 25%, черновики 30% (слепая оценка админами), без выдуманных пунктов 20% (выдуманный пункт обнуляет обращение), kk/uz 15%, цена ≤ $0,002 и p95 ≤ 5 с — 10%. RAG по правилам обязателен.

Команда — новички, общение и документация на русском. Объяснять просто, без жаргона.

## Обязательные правила работы

1. **Данные кейса нельзя публиковать и класть в git.** Они лежат в `../grand-support-copilot-handout-2026-10-27/handout`. В `.gitignore` закрыты данные, `artifacts/` (содержат тексты из данных), `out/`, `.env`. Не коммитить примеры обращений в код и документы.
2. **Ни одного выдуманного пункта правил.** Черновик ссылается только на пункты, найденные поиском (`copilot/rag.py`), каждая ссылка проверяется (`copilot/policy.py`). Любое изменение шаблонов и черновиков проверять `make test` и `make eval` (поле `safety.invalid_citations` должно быть 0).
3. **Каждая функция включается флагом и откатывается.** Нет ключа LLM, файла модели или истории — сервис работает как раньше (см. настройки в [docs/03-architecture.md](docs/03-architecture.md)).
4. **Решение кода, текст — шаблон или LLM.** LLM не решает категорию и «нужен ли человек», только пишет текст в рамках решения.
5. **Честные метрики.** Разметки категорий нет; проценты по категориям — по прокси-меткам из ответов админов (`copilot/weak_labels.py`). Так и писать.
6. Комментарии в коде на русском, коротко, по делу.

## Как запустить и проверить

```bash
cd support-copilot
.venv/Scripts/python -m pytest -q                     # тесты (Windows; на Linux: python -m pytest -q)
.venv/Scripts/python -X utf8 scripts/eval_valid.py --stage current   # метрики -> out/eval_current.json
COPILOT_DEDUP=0 .venv/Scripts/python -X utf8 scripts/eval_retrieval.py   # качество поиска -> out/eval_retrieval.json
.venv/Scripts/python -X utf8 scripts/load_queue.py --limit 300 --with-reference  # демо-очередь -> out/admin.db
.venv/Scripts/python -m uvicorn copilot.api:app --port 8000   # http://localhost:8000/admin
```

Пересборка артефактов из train (после изменений в правилах классификации — обязательно `train`): `make index`, `make dedup`, `make train`, `make templates` (массовые прогоны — с `COPILOT_RAG_EXAMPLES=0`).

## Подводные камни окружения

- **Windows, нет `make`.** Команды из `Makefile` запускать через `.venv/Scripts/python`. Для кириллицы в выводе — `python -X utf8`.
- **Bash heredoc портит обратные слеши**: `\\b` в heredoc превращается в символ backspace. Регулярные выражения не правьте через heredoc — только редактором файлов или скриптом, записанным через Write. Проверка: в `.py` не должно быть символа `\x08`.
- **Превью в Claude Desktop:** конфиг `D:\Projects\Decentrathon 6\.claude\launch.json`, имя `copilot-admin`, порт 8010. Сервер без автоперезагрузки — после правок Python перезапускать.
- **Ключа LLM на машине нет.** Ключ кладётся в `support-copilot/.env` (`ANTHROPIC_API_KEY=...`). Переменная `ANTHROPIC_BASE_URL` в окружении указывает на api.anthropic.com — это нормально.
- **Кэш** `artifacts/triage_cache_train.pkl` (для `suggest_templates.py`) устаревает при изменении логики — удалить перед повторным поиском шаблонов.

## Состояние (30 октября 2026)

Готовы циклы: 1) обращение → ответ с RAG; 2) ответ → решение админа → обучение; 3) порядок: срочность, дубли, автоответы, прогон истории; 4) история → новые шаблоны → применение; 5) метрики на прокси-метках. Подробно — [docs/04-status.md](docs/04-status.md), история экспериментов — [docs/research-log.md](docs/research-log.md).

Ключевые цифры на valid (1000): выдуманных ссылок 0; поиск находит пункт админа в топ-5 в 91,7%; категория 86,1% (прокси); решение черновика = решение админа 59,8%; p95 37 мс; 61 тест.

Важные решения и находки:
- DM, читы, мошенничество без видео → черновик «нужна видеозапись» (ЖБ 1.2.2 + ЖБ 1.2.1), флаг `COPILOT_NEED_VIDEO`.
- Классификатор не перебивает правила для читов, DM, мошенничества, рекламы и «не жалобы» без уверенности 0,8 (`classify.PROTECTED`): в слабой разметке перекосы.
- Дубль — только пока первое обращение без ответа (`copilot/dedup.py`).
- «+» в репорте — просьба о телепорте на мероприятие.
- 775 из 839 заявителей valid есть в train: внутреннюю проверку делить по заявителям.
- Автоответы из сырых прошлых ответов админов пробовали — шумно, отказались; готовые ответы только из принятых шаблонов.
