# Support Copilot для Grand Mobile

Decentrathon 6.0, кейс 03. Сервис, который разбирает обращения игроков: определяет язык, категорию и срочность, находит нужные пункты правил, пишет черновик ответа со ссылками на них и говорит, нужен ли человек. Плюс интерфейс админа с очередью, правками и новыми шаблонами.

## Быстрый старт

Нужны Python 3.12+ и данные кейса в папке `../grand-support-copilot-handout-2026-10-27/handout` (путь меняется переменной `COPILOT_DATA_DIR`). Данные в репозиторий не кладём — так требуют условия кейса.

Установить зависимости:

```bash
make setup
```

Собрать модель и индексы из train (около 10 минут, результат в `artifacts/`):

```bash
make artifacts
```

Загрузить демо-очередь и запустить сервис, затем открыть `http://localhost:8000/admin`:

```bash
make queue
```

```bash
make serve
```

Разобрать файл обращений по контракту кейса:

```bash
make predict IN=tickets.jsonl OUT=pred.jsonl
```

Проверки:

```bash
make test
```

```bash
make eval
```

На Windows без `make` те же команды запускаются через Python: `python -m copilot.predict --in tickets.jsonl --out pred.jsonl`, `python -m uvicorn copilot.api:app --port 8000` и т.д. — см. `Makefile`.

Языковая модель включается сама, если в файле `.env` есть строка `ANTHROPIC_API_KEY=...`. Без неё сервис работает полностью на шаблонах.

## Структура

```
copilot/            сервис: разбор, поиск (RAG), шаблоны, проверки, API, интерфейс админа
  static/admin.html интерфейс админа
scripts/            сборка индексов, обучение, оценка, прогон истории, поиск шаблонов
tests/              автотесты (pytest)
docs/               документация
artifacts/          модель и индексы из train (не в git)
out/                очередь админа, отчёты, прогоны (не в git)
```

## Источники

Только данные кейса. Языковая модель (опционально) — Claude Haiku через Anthropic API. Шрифт интерфейса — Golos Text (Google Fonts, OFL).
